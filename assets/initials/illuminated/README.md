# Illuminated initials (A to Z)

Twenty-six decorative drop-cap letters in a Renaissance woodcut style, solid black ink on transparent, each in a double-ruled square frame.

Made for Booker by its author with an AI image generator (one 2048 x 2048 sheet of A to Z), then cut into separate letters. They are released with the rest of Booker under the MIT licence (see the repository `LICENSE`).

Used for the "Illuminated" chapter-opening style in the editor and in exports.
